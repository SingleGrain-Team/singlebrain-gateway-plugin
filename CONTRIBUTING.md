# Contributing

This repository is a public plugin shell for the hosted SingleBrain Gateway MCP server. It is not the server itself.

Useful contributions are fixes to manifests, install snippets, and docs in this repo. Changes to the live server are out of scope here.

## Before you open a pull request

1. Keep the MCP remote URL exactly `https://gateway.singlebrain.com/mcp`, with no query string.
2. Do not commit keys, tokens, or `.env` files. Leave placeholders in example configs.
3. Keep JSON manifests valid.
4. Website links in the README may carry UTM tags. The MCP URL must not.

Questions: [support@singlebrain.com](mailto:support@singlebrain.com).
